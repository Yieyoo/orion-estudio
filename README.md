# Orion Studio

Sitio de presentación para Orion Studio, con una selección de proyectos conceptuales, servicios y contacto.

## Abrir localmente

Abre `index.html` en un navegador o ejecútalo con Live Server desde VS Code.

El sitio carga las tipografías de Google Fonts y las fotografías de Unsplash, así que necesita conexión a internet para mostrarse completo.

## Cambiar el color de acento

En `assets/css/styles.css`, cambia `--blue` dentro de `:root`.

## Publicar en GitHub Pages

1. Sube los archivos al repositorio.
2. Abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.

Los proyectos de Jardín 44, Finca La Fortaleza y Fuego & Sabor son conceptos demostrativos, no trabajos de clientes.
