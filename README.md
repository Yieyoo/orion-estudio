# Orion Studio

Estudio digital independiente: dirección creativa premium, composición editorial, tipografía monumental (Space Grotesk + Manrope), paleta negro/grafito/violeta eléctrico, sistema orbital en el hero, cursor personalizado, movimiento vinculado al scroll con GSAP, portafolio conceptual y diseño responsive.

## Abrir localmente
1. Descomprime el ZIP.
2. Abre `nitido-studio-atelier` en VS Code.
3. Ejecuta `index.html` con Live Server para probarlo.

Se usan imágenes remotas de Unsplash, Google Fonts y GSAP CDN. Para ver la composición tal como está diseñada, abre el sitio con conexión a internet. Si las imágenes no cargan, verifica tu conexión.

## Personalizar WhatsApp
En `assets/js/main.js`, cambia `5210000000000` por tu número con código de país, sin `+`, espacios ni guiones.

## Personalizar el color de acento
En `assets/css/styles.css`, la variable `--accent` (definida en `:root`) controla el único color de acento de la marca (violeta eléctrico `#7c4dff`). Cámbiala ahí para ajustar todo el sitio de una sola vez.

## Publicar en GitHub Pages
1. Crea un repositorio público y sube todos los archivos.
2. Abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda y espera la URL pública.

## Importante
Los proyectos de Jardín 44, Finca La Fortaleza y Fuego & Sabor son conceptos demostrativos. No se presentan como proyectos reales de clientes. Reemplázalos por casos reales a medida que los tengas.
